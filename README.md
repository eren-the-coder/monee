# Monee

Application React + TypeScript pour gérer des économies et combos d'achats.

## Installation

```bash
npm install
```

## Démarrage local

```bash
npm run dev
```

Puis ouvrez le navigateur sur l'URL affichée par Vite.

## Build de production

```bash
npm run build
```

## Vérification TypeScript

```bash
npm run typecheck
```

## Notes

- Le projet utilise Vite, React, TypeScript, Tailwind CSS et lucide-react.
- Les types sont fournis par `@types/react`, `@types/react-dom` et par les packages eux-mêmes.
